# v0.2.0

> 发布日期：2026-11-18（tag `v0.2.0`，构建于 `main`）
> 上一版：`v0.1.0`（2026-10-17）

## 这一版做了什么

### 引擎 / 跳过准确率

- **盲点校验重做**（`300d304`）：`node == null` 时不再看"跳过字样"，改判「点击时还在的目标应用窗口 1 秒后是否消失」；
  读不到就不记结论并停止本次探测。真机 14 次启动：盲点结论 25 未生效 / 6 成功 / 0 无法判断，成功全部来自窗口消失证据。
- **志愿汇时机修复**（`77e1033` → `3036f8d`）：规则新增 `blindMinAgeMs` + 右侧盲点优先；
  2026-11-18 M2 复核再把门槛从 2400ms 提到 **5200ms**，让文本策略先出手：
  12 轮真机点击/广告 **1.33 → 0.92**，11 轮首点文本命中、0 失败。
- **校验空读重试**（`3036f8d`）：点击后 1 秒读不到界面时，400ms 后重试一次（只重试一次）。
  云运动"无法确认"从 2/2 降到 1/15。
- **同包落地页识别阶段一**：强特征命中时不计成功也不计失败；弱特征只记日志（阶段二等样本）。

### Android 17 / ColorOS 17 适配

- 应用内新增「无障碍被系统关掉了？」指引卡（`e3ebb75`）：清理后台会关闭无障碍，**开启「自启动」后重新打开应用可自动恢复**（实测）。
- 文档 `docs/usage-oppo-coloros.md` 与 `docs/next-steps.md` 记录了复现步骤、恢复顺序与预防设置。

### 界面（P1 / P2）

- 状态卡按状态收拢操作：工作态只留小「设置」，未开启/已停止才显示主按钮与 ADB 命令。
- 统计空态：无数据时隐藏复制/清零，只显示居中引导；破坏性操作加二次确认。
- 合并「设置与调试」卡（夜间模式 + 高级 ADB 命令），整卡数量 6 → 5。
- 调试日志：I/W/E 级别配色、行高与内边距、底部渐隐。
- 强调色**自动跟随系统**（Android 12+ 动态取色；表面色保持中性灰，旧系统回退默认紫）。
- 字号统一（正文 14sp / 提示 12sp），按钮层级统一为 TextButton + 一个实心主操作。

### 质量

- 单元测试 **176 项全绿**；`build.ps1` debug/release 构建均通过。
- M2 真机覆盖矩阵：15 个已安装规则应用 × 2 轮（30 次启动）：点击/广告 1.13、成功率 87%、误点 0。
- Release 冒烟：卸载 debug 后干净安装 `app-release.apk`，版本 0.2.0 / versionCode 2，服务正常绑定、界面正常。

## 已知问题

- 同包落地页**弱特征**未纳入统计（需 ≥5 条人工确认样本，目前仅 1 条弱候选）。

- 4 条规则对应应用未安装（微博 / 知乎 / 贴吧 / 微信读书），暂无法真机验证。
- 摇一摇广告、纯自绘且无节点信息的跳过按钮仍做不到。

## 升级提示

- 从 v0.1.0 覆盖安装后，无障碍服务若未自动恢复：按应用内指引打开一次「广告跳过」，或到系统设置重开无障碍。
- Android 17 / ColorOS 17 用户请务必开启「自启动」，并避免在最近任务里「清除」本应用。
